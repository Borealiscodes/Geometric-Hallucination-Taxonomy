🌌 1. Project Overview

The Geometric Hallucination Taxonomy (GHT) is a structural‑AI research project that formalizes hallucinations as geometric instabilities in latent manifolds.  
The project consists of:

- a unified preprint  
- a Python geometric‑diagnostic toolkit  
- a LaTeX mathematical spine  
- Lean formalization scaffolding  
- figures and diagrams  
- reproducible notebooks  
- operator‑level tests  

This roadmap outlines the full development workflow.
